# Amazon_ReturnOrder_Analysis

# Problem Statement
Amazon faced challenges with order cancellations and returns, which not only reduce revenue but also disrupt inventory management, logistics, and operational efficiency. My goal was to analyze the drivers of cancellations and returns and provide actionable insights to minimize them while improving customer satisfaction.

# Key Insights
*Kurta category had the highest cancellation rate (15.26%), while Saree had the lowest.
*Kurta (XL & M sizes) and Set (S & M sizes) recorded the most cancellations, while XS and 3XL sizes had fewer.
*Bengaluru showed the highest number of cancellations (12.14%), followed by Hyderabad and Mumbai.
*States like Maharashtra & Karnataka generated high order volumes but also showed cancellation concerns.
*Price bands: Sets above ₹1000 had the highest order volume but also a 9% cancellation rate.

# Recommendations
* Improve Sizing & Product Details -
   Revise sizing guides and include accurate product descriptions,
   Strengthen quality control for XL/M kurtas and S/M sets.
* Optimize Pricing Bands-
  Focus on ₹500–₹1000 and >₹1000 ranges, where cancellations are high,
  Improve value perception through better packaging, quality, or offers.
* Target High Order Regions-
  Prioritize Maharashtra and Karnataka for region specific interventions,
  Refine policies/offers tailored to these states.
* City Level Strategy
  Focus on Bengaluru and Hyderabad, which combine high orders with high cancellations,
  Enhance delivery reliability and customer trust in these cities.
* Refine Return Policies-
  Reduce misuse of return policies by stricter checks,
  Offer personalized solutions like tailored recommendations to minimize returns.

# Tools Used
SQL → Data extraction, joining multiple tables, segmentation analysis.

# Conclusion
By analyzing cancellations across categories, sizes, cities, and price ranges, I identified patterns that impact Amazon’s profitability and customer trust. Implementing these insights will help Amazon:
Reduce cancellations & returns
Improve operational efficiency
Boost customer satisfaction and retention
